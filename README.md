# Image Super-Resolution with SRCNN (DIV2K)

Replication of the Stanford CS229 project "Image Super-Resolution Via a Convolutional Neural
Network" (Garber, Grossman, Johnson-Yu, 2020) for the UE24CS352A ML mini project.

**Note:** the original authors did not publish code. This is our own implementation.
The SRCNN model and PSNR utilities are adapted from
[yjn870/SRCNN-pytorch](https://github.com/yjn870/SRCNN-pytorch); the DIV2K data pipeline,
baselines, training loop, ablations and plots are written by us.

Setup and run instructions: coming soon.

Dataset: DIV2K (Agustsson & Timofte, CVPR Workshops 2017).
